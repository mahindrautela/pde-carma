Ground-Truth-Free Selection in Conditional Generative PDE Surrogates via Cyclic Consistency

CARMA selects among stochastic PDE rollouts using forward–backward consistency. It uses only the observed initial state and requires no test-time parameter updates.

Anonymous code ↗ Method ↓

Method

Bidirectional training and cyclic rollout selection

A shared direction-conditioned transformer learns adjacent PDE-state transitions in both time directions. At inference, CARMA ranks each forward rollout using its backward reconstruction.

Training

One parameter-shared transformer learns forward and backward transitions from ordered adjacent-state pairs.

Candidates

Flow-matching or diffusion surrogates generate multiple autoregressive rollouts from the initial state.

Selection

Each terminal state is rolled backward. CARMA returns the forward path with the smallest path-wise cyclic discrepancy.
